# 📘 База данных проекта «Кухни Вязники»

## Общая информация

База данных построена на **PostgreSQL** и используется для хранения данных интернет-сайта мебельного магазина.  
Основная цель структуры — обеспечить масштабируемость, чистоту данных и удобство интеграции с **FastAPI + SQLAlchemy**.

## Составные части

- **Пользователи и авторизация**
- **Категории и товары**
- **Характеристики товаров**
- **Отзывы**
- **Реализованные проекты**
- **Записи на замер**
- **Рекламные баннеры**

## 10. Таблица `project_products` — связь проектов и товаров

> Эта таблица реализует связь "многие ко многим" между `projects` и `products`.  
> Она позволяет хранить список товаров, использованных в каждом проекте.

| Поле       | Тип                    | Назначение           |
| ---------- | ---------------------- | -------------------- |
| project_id | int (FK → projects.id) | Проект               |
| product_id | int (FK → products.id) | Использованный товар |

*(массив ссылок на товары реализуется через выборку по project_id)*

## 🔗 Основные связи между таблицами

- **categories → products** — 1 ко многим  
- **products → product_images** — 1 ко многим  
- **products ↔ attributes** — многие ко многим через `product_attributes`  
- **products → reviews** — 1 ко многим  
- **projects → project_images** — 1 ко многим  
- **projects ↔ products** — многие ко многим через `project_products`

## 📌 Примечания

- Все даты (`created_at`, `updated_at`) рекомендуется заполнять автоматически на уровне ORM.  
- Для изображений предполагается использование CDN или S3-совместимого хранилища.  
- В будущем можно добавить таблицу `orders`, если появится онлайн-заказ.  
- Для админки можно использовать FastAPI Admin или кастомный фронт на Flutter Web.
